# TanStack Router

## Overview

File-based routing with full type safety. The Vite plugin auto-discovers route files in `src/routes/` and generates `routeTree.gen.ts`. Routes are code-split automatically.

## Route file conventions

| File path | Route |
|-----------|-------|
| `src/routes/__root.tsx` | Root layout (wraps all routes) |
| `src/routes/index.tsx` | `/` |
| `src/routes/about.tsx` | `/about` |
| `src/routes/items/$itemId.tsx` | `/items/:itemId` |
| `src/routes/items/index.tsx` | `/items` |
| `src/routes/_layout.tsx` | Pathless layout route |

## Creating routes

Use `createFileRoute` — the path string is auto-generated by the plugin:

```typescript
import { createFileRoute } from "@tanstack/react-router";

export const Route = createFileRoute("/items/")({
  component: ItemsPage,
  loader: ({ context }) =>
    context.queryClient.ensureQueryData(itemListOptions()),
});

function ItemsPage() {
  const items = Route.useLoaderData();
  return <ItemList items={items} />;
}
```

## Root route

Uses `createRootRouteWithContext` to provide typed context (QueryClient) to all routes:

```typescript
import { createRootRouteWithContext, Outlet } from "@tanstack/react-router";
import type { QueryClient } from "@tanstack/react-query";

interface RouterContext {
  queryClient: QueryClient;
}

export const Route = createRootRouteWithContext<RouterContext>()({
  component: () => (
    <div>
      <nav>{/* navigation */}</nav>
      <Outlet />
    </div>
  ),
});
```

## Router creation (main.tsx)

```typescript
const queryClient = new QueryClient({
  defaultOptions: {
    queries: { staleTime: 1000 * 60, retry: 3 },
  },
});

const router = createRouter({
  routeTree,
  defaultPreloadStaleTime: 0,
  context: { queryClient },
});

// Type registration for type-safe navigation
declare module "@tanstack/react-router" {
  interface Register {
    router: typeof router;
  }
}
```

## Loaders

Loaders run before the route renders. Use them to preload query data:

```typescript
export const Route = createFileRoute("/items/")({
  loader: ({ context }) =>
    context.queryClient.ensureQueryData(itemListOptions()),
});
```

- `ensureQueryData` returns cached data if fresh, fetches otherwise
- The loader result is available via `Route.useLoaderData()`
- Combine with `useSuspenseQuery` in the component for reactive updates

## Navigation

```typescript
import { Link, useNavigate } from "@tanstack/react-router";

// Declarative
<Link to="/items/$itemId" params={{ itemId: "42" }}>View Item</Link>

// Imperative
const navigate = useNavigate();
navigate({ to: "/items/$itemId", params: { itemId: "42" } });
```
